사용 설명서

필요한 항목을 펼쳐보세요.

운동운동하고 기록하기

한 세트 저장

요일·날짜 선택 → 실제 kg·횟수 입력 → 세트 저장

버튼의 숫자는 저장할 세트 번호예요. 무게는 +·− 버튼으로 조절할 수 있어요.

목표값 읽기

2세트·8~12회는 계획한 세트 수와 반복 범위예요.

kg·회 입력칸에는 실제 수행한 값을 적어요. 계획을 바꿔도 지난 기록은 바뀌지 않아요.

RIR 읽기

RIR 2는 같은 자세로 약 2회 더 할 수 있는 여유예요.

앱은 실제 RIR이나 모든 세트의 수행을 자동으로 확인하지 않아요.

무게 안내 읽기

선택일 이전의 최근 두 기록일을 비교한 참고 정보예요.

각 날짜의 최고 무게 세트로 비교하며 같은 무게에서는 반복수가 많은 세트를 써요. 무게가 같고 두 기록 모두 목표 상한 이상이면 증량 참고, 하한 미만이면 감량 참고예요. 조건이 맞지 않으면 판단을 보류해요. 실제 수행과 장비의 중량 간격도 확인하세요.

제안 무게

흐린 숫자는 그날 기록 또는 이전 회차의 무게예요.

그대로 저장하거나 실제 수행한 값으로 바꾸세요. 무게 안내를 펼치면 비교 근거를 볼 수 있어요.

저장한 기록

최근 저장 기록 관리에서 날짜·무게·횟수를 수정해요.

이전 기록 줄을 누르면 최근 5세트와 최고 기록을 확인해요.

직접 기록

루틴에 없는 운동은 + 직접 기록으로 추가해요.

목록에 없는 이름도 입력할 수 있어요. 운동 관리 목록에는 자동 추가되지 않아요.

루틴 편집

요일 선택 → 루틴 편집 → 변경 → 루틴 저장

제목·종목·순서·세트·횟수·RIR을 편집해요. 변경 취소는 편집 전으로 되돌려요.

고급 옵션

운동 초기화·기본 루틴 적용은 고급 옵션에 있어요.

기본 루틴은 월~토를 교체해요. 일요일은 유지돼요. 실행 전 확인창의 변경 범위를 확인하세요.

운동 메모

설정에서 추가하고 저장한 메모만 표시돼요.

메모가 없으면 메모 카드는 보이지 않아요.

기록찾기 · 수정 · 삭제

기록 찾기

기간·부위·종목명으로 조회 범위를 좁혀요.

전체 펼치기·접기 또는 부위 선택으로 목록을 정리해요.

수정과 복제

세트 기록을 누르면 날짜·무게·횟수를 수정해요.

마지막 세트와 같은 기록 추가는 해당 날짜에 같은 내용의 1세트를 추가해요.

하단에서 접기

종목 끝의 접기를 누르면 제목 위치로 돌아가요.

수정 중인 기록은 먼저 저장하거나 취소하세요.

삭제 범위

한 세트 삭제 후에는 잠시 되돌릴 수 있어요.

종목 전체 삭제는 조회 기간과 관계없이 해당 종목의 모든 기록을 삭제해요. 기록 관리의 전체 삭제는 현재 플랜 전체 기록이 대상이에요. 둘 다 되돌릴 수 없어요.

루틴주간 계획 · 임시 루틴

주간 계획

월~일의 계획과 부위별 계획 세트를 확인해요.

계획 세트와 실제 저장한 기록은 별개예요. 기본 루틴 편집은 운동 탭에서 해요.

이번 주 조정

남은 운동일과 시간을 정해 조정 요청문을 만들어요.

기록 외 수행 여부와 추가 조건도 확인하세요. 외부 AI에 요청문을 전달한 뒤 결과를 검토하세요.

임시 루틴 가져오기

임시 루틴 JSON 선택 → 내용 확인 → 이번 주 적용

플랜 백업 JSON과는 다른 파일이에요. 잘못된 형식은 안내에 따라 올바른 가져오기를 사용하세요.

적용 후 관리

임시 루틴은 해당 기간에만 사용해요.

적용 내용을 확인하고 편집하거나 임시 적용을 취소할 수 있어요.

통계운동량 · 최고 기록 · 변화

기록 범위

현재 플랜 또는 모든 플랜 합산을 선택해요.

이 선택과 아래 조회 기간은 서로 다른 조건이에요.

부위별 운동량

주간·월간을 선택하고 화살표로 기간을 바꿔요.

직전 기간과 비교해요. 볼륨은 무게×횟수의 합계이며 값이 빠진 세트는 제외해요. 부위끼리의 볼륨 비교보다는 같은 부위의 변화를 보세요.

기록으로 이동

부위 행을 누르면 그 기간의 기록이 펼쳐져요.

기록 탭은 현재 플랜 기준이에요. 모든 플랜 합산에서 이동할 때도 같아요.

3대 운동

전체 기간의 실측·추정 1RM과 합계를 보여줘요.

실측은 1회 기록의 최고 무게, 추정은 2회 이상 기록의 Epley 환산값이에요. 고반복에서는 오차가 커질 수 있어요. 기록이 있는 종목만 합산해요.

관심 종목

기록이 있는 종목을 최대 5개 고정해요.

전체 기간 기준이에요. 조회 기간을 바꿔도 관심 종목에는 적용되지 않아요.

조회 기간

이번 주·이번 달·전체 기간 또는 달력에서 선택해요.

직접 선택은 시작일과 종료일을 차례로 눌러요. 기록한 날과 아래 종목별 변화에 적용돼요.

종목별 변화

추정 1RM·최고 무게·일별 볼륨을 전환해요.

날짜를 선택하면 해당 값을 확인할 수 있어요. 최고 기록 영역은 조회 기간과 무관한 전체 기간 기준이에요.

운동 관리종목 목록과 목표값

검색·추가

부위와 이름으로 찾고 + 종목 추가로 등록해요.

새 종목의 이름·세트·횟수·RIR을 입력하세요. 종목 목록과 목표값은 모든 플랜에서 공유해요.

목표값 수정

종목명을 눌러 세트·횟수·RIR을 수정해요.

변경사항은 자동 저장돼요. 종목 삭제는 확인창에서 모든 플랜에 적용되는 범위를 확인해요.

3대운동 배지

배지가 붙은 종목이 3대 운동 집계 대상이에요.

해당 종목을 삭제하면 집계에 영향을 줄 수 있어요.

초기화

하단 종목 설정 → 기본 종목으로 초기화

모든 플랜의 공통 종목 목록과 목표값을 기본값으로 되돌려요. 운동 기록과 루틴은 유지돼요.

설정플랜 · 백업 · 메모

플랜 관리

플랜을 눌러 전환하고 추가·이름 변경으로 관리해요.

사용 중인 플랜은 체크로 표시해요. 다른 플랜 삭제 전에는 백업하세요.

파일 백업

현재 플랜 또는 전체 플랜을 파일로 저장해요.

백업 상태는 현재 플랜의 변경 여부와 내보낸 날짜를 기준으로 표시해요. 파일이 실제로 보관됐는지도 확인하세요.

복원

가져오기에서 플랜 백업 JSON을 선택해요.

현재 플랜에 가져오면 루틴은 교체하고 기존 종목·기록은 유지하며 새 항목을 추가해요. 새 플랜으로 가져오기는 별도 복원이에요. 전체 백업은 새 플랜들로 추가돼요. 공통 종목은 없는 항목만 추가하고 기존 목표값은 유지해요.

백업 경로

백업 경로 설정에서 저장 폴더를 선택해요.

지원하지 않는 브라우저에서는 다운로드 방식으로 저장해요. 폴더 선택은 자동 백업 예약이 아니에요.

텍스트 내보내기

현재 플랜의 기록을 확인하고 복사해요.

공유용이며 백업 복원 파일로 사용할 수 없어요.

메모 추가

+ 메모 추가 → 제목·내용 입력 → 메모 저장

저장한 메모는 운동 탭에 표시돼요. 삭제도 메모 저장을 눌러 확정해요. 루틴·기록에는 영향이 없어요.

설치와 업데이트

브라우저 메뉴에서 앱 설치 또는 홈 화면에 추가를 선택해요.

새 버전 확인은 앱 정보의 업데이트 확인을 사용하세요.

데이터 보관 주의

기록은 현재 기기·브라우저에 저장돼요.

설치만으로 백업되지 않아요. 기기·브라우저·주소 변경이나 데이터 삭제 전에 파일로 백업하세요.
