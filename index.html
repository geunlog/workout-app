사용 설명서

메뉴별로 필요한 항목을 펼쳐보세요.

운동운동하고 기록하기

운동 시작·저장

운동 → 요일·날짜 선택 → 실제 kg·횟수 입력 → 세트 저장. 목표 세트·횟수는 계획이며, 저장한 실제 기록과 달라요.

앱 AI 기본 루틴

운동 → 루틴 편집 → AI 루틴 추천 → 기본 루틴 만들기. 조건을 입력하고 제안을 확인한 뒤 선택한 요일에 적용해요.

직접 기록·무게 안내

루틴에 없는 종목은 + 직접 기록으로 입력해요. 무게 안내는 이전 기록에 따른 참고이며 자동 증량하지 않아요.

종목 메모

종목 메모 → 수정 → 저장. 현재 플랜의 해당 종목에 최대 500자이며 빈 내용으로 저장하면 삭제돼요.

기록날짜·종목별 조회

조회와 달력

기록 → 날짜별에서 날짜·달력을 선택하거나, 종목별에서 기간·부위·종목명으로 찾아요. 모든 플랜 조회 중 다른 플랜 기록을 수정하려면 해당 플랜으로 전환하세요.

수정·복제·삭제

세트 기록을 눌러 날짜·무게·횟수를 수정해요. 마지막 세트와 같은 기록 추가는 1세트를 복제하며 한 세트 삭제는 잠시 되돌릴 수 있어요.

삭제 범위 확인

종목 전체 삭제는 조회 기간과 무관하게 해당 종목의 모든 기록을 삭제해요. 기록 관리의 전체 삭제는 현재 플랜 전체가 대상이며 둘 다 되돌릴 수 없어요.

루틴기본·이번 주 임시 루틴

기본 루틴 관리

운동 → 루틴 편집에서 종목·순서·세트·횟수·RIR을 바꾸고 루틴 저장을 눌러요. 변경 취소는 마지막 저장 상태로 돌아가며 루틴 탭에서는 주간 계획을 확인해요.

외부 AI로 기본 루틴 만들기

운동 → 루틴 편집 → AI 루틴 추천 → 외부 AI로 기본 루틴 만들기. AI 요청문 복사 → 원하는 AI에서 상담 → 추천 결과 JSON 붙여넣기 → JSON 검증·미리보기 → 기본 루틴 적용 순서예요.

운동시간 초과

수정하기로 수정 요청문을 복사하거나 그대로 진행으로 현재 구성의 초과시간만 수용해요. 수용 완료 후에도 기본 루틴 적용 전에는 저장하지 않으며 JSON·관련 조건을 바꾸면 다시 확인해야 해요.

외부 AI 이용 주의

앱 AI와 달리 요청문을 직접 전달하며 결과 JSON의 정확성은 보장되지 않아요. 복사 실패 시 요청문 확인에서 직접 복사하고, 새로고침·강제 종료 시 요청 연결이 해제될 수 있어요.

이번 주 조정·임시 루틴

루틴 → 이번 주 루틴 조정에서 실제 기록·남은 일정·시간을 확인하고 AI로 루틴 제안받기를 눌러요. 제안 적용은 이번 주 임시 루틴에만 반영되며 기본 루틴과 지난 기록은 유지돼요.

외부 추천 파일·적용 후 관리

이번 주 루틴 조정 → 외부 AI로 직접 요청하기에서 요청 복사·추천 파일 가져오기를 사용해요. 임시 적용 취소는 기본 루틴으로 돌아가며 이미 저장한 운동기록은 유지해요.

통계운동 통계·체형 변화

운동 통계

통계 → 운동 통계에서 기간·플랜별 실제 저장 세트와 운동량을 확인해요. 루틴의 계획 세트와 달라요.

체형 측정

통계 → 체형 변화 → + 기록 추가에서 측정일시와 값을 입력해요. 체형 기록은 플랜 공통이며 입력 오류가 있으면 원본을 유지해요.

그래프·기간 선택

체형 변화에서 지표와 1·3·6개월·전체 또는 직접 설정 기간을 골라요. 실제 측정일시 간격을 표시하며 30일 넘는 공백은 선을 끊어요.

원본 이력·비교

원본 측정 선택의 슬라이더·이전·다음으로 밀집된 기록도 모두 확인하고 수정·삭제할 수 있어요. 최근 값은 지표별로 다를 수 있으며 이전 측정 또는 설정한 기준 기록과 비교해요.

체형 기록 백업

체형 기록 백업에서 내보내기·불러오기를 사용해요. 체형 기록은 전체 플랜 백업에도 포함돼요.

운동 관리종목·목표값

종목 등록·수정

운동 관리에서 종목을 검색·추가하고 목표값을 수정해요. 목표 무게·횟수는 실제 운동기록과 별개예요.

초기화 전 확인

초기화는 확인창에 표시된 범위를 확인한 뒤 실행하세요. 중요한 데이터는 먼저 파일로 백업해두세요.

설정데이터·앱 정보

플랜·메모

설정에서 플랜을 관리하고 운동 메모를 편집해 저장해요. 다른 플랜으로 전환하기 전 미저장 변경사항을 확인하세요.

백업·복원

설정에서 파일 백업 후 필요한 범위로 복원해요. 불러오기 전 적용 대상과 덮어쓰기 안내를 확인하고 기존 데이터도 별도로 보관하세요.

업데이트·데이터 보관

설정의 앱 버전을 확인하고 업데이트 안내에 따라 적용해요. 기록은 이 브라우저에 저장되므로 사이트 데이터 삭제·브라우저 초기화 전 반드시 백업하세요.
