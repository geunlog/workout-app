### Cause and minimal changes

The routine letter label had a fixed 18px width, so the two-character Korean label wrapped into two lines. It now uses intrinsic width with nowrap. Titles use keep-all with an overflow fallback; the set total does not shrink. Long exercise names keep Korean/parenthesized words together where space permits. On mobile, the AI date label spans both columns above two full-width controls, avoiding the former 65/76px label squeeze. Displayed dates/status values are unchanged.

Tab descriptions, muscle labels, period labels and scope hints change from 11px to 12px. The weekly caption is also 12px. No broad typography redesign.
