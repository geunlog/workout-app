기준: 앱 v155 main `1a7df1a6a5bb02e85f11839821bda489dfa46c8e`, Worker V128 main `ac3f5b315550bb6efa62aca0062b572c07322e53`. 앱 후보 v156, `work/WORKOUT-20261020-002-ui`에서 개발. main/운영 변경 없음.

## 변경 이유 및 전후

- 종목 메모: 바로 입력/키보드 진입 → 기본 조회(메모 없음 포함) + 수정 버튼. 취소는 기존 본문 조회로 돌아가고 닫기는 모달 종료. visualViewport 높이/offset 변경을 따라 모달이 보이는 화면에 머물고, 본문 스크롤과 고정 액션을 분리. 500자, 빈 저장 삭제, 프로필 분리, 오류시 원본 유지 정책 보존. 텍스트만 렌더링한다.
- 날짜별 기록: 종목별 필터가 날짜별 결과까지 숨기던 공유 구조 → 날짜 선택/이동/기록일 바로가기 중심. 종목 검색/기간/부위는 종목별에서 유지되며 날짜별로 갔다 돌아와도 복원된다. 날짜별은 숨은 필터를 적용하지 않는다. 프로필/범위 변경으로 유효하지 않은 선택은 가장 최근 기록일로 보정한다. 직접 고른 빈 날짜는 단순 재렌더에서 유지한다.
- 달력: 날짜별 네이티브 input을 기존 앱 달력 컴포넌트로 통일. 선택/오늘/미래 비활성, 취소/적용, 월 이동 유지. 종목별은 단일 날짜 선택 없이 기간 검색만 제공한다.
- 기본 AI 설문: 목표·경력 → 일정·시간 → 이번 요청의 세 단계, 요일/시간 카드와 주요 CTA 구분. 이번 주 조정은 수행 기록 → 남은 일정 → 추가조건 순서 유지, 카드/라벨 위계 개선.
- API/시간 모델/운영 endpoint/저장소 키/백업 스키마 미변경. Worker V128과 독립 사용 가능. v156는 리소스 변경에 따른 개발 후보 번호로 운영 버전이 아니다.
