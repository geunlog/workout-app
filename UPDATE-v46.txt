운동 루틴 v46 업데이트

압축 안의 index.html, app.js, sw.js, bump-version.sh를 기존 GitHub의 같은 경로에 덮어올리세요.
style.css, manifest.webmanifest, 아이콘은 기존 파일을 유지합니다.

변경 사항
- 전체 플랜 백업도 파일에 포함된 각 플랜의 백업 상태를 갱신합니다.
- 저장창/지정 폴더 쓰기 완료 후에만 저장 완료 상태로 반영합니다.
- 일반 다운로드는 다운로드 요청 상태로 기록하며 파일 앱 확인 안내를 유지합니다.
- 저장을 취소하면 백업 상태를 갱신하지 않습니다.
- 배포 날짜는 Asia/Seoul 기준입니다.
- 버전 스크립트에 양의 정수 입력 검증을 추가했습니다.

개발 인수인계 v45 문서의 버전 변경 명령은 다음으로 대체합니다.
bash bump-version.sh 47
실행 권한을 별도로 설정하지 않아도 됩니다. 스크립트는 Bash와 GNU sed 환경에서 실행합니다.

기능 확인: 단일/전체 백업의 저장, 다운로드, 취소, 상태 저장 실패 경로 검사 통과.
JS/셸 문법 검사 통과. 실제 휴대폰 UI 검사는 수행하지 않았습니다.
폰트 내장과 백업 파일 5MB 제한은 이번 수정 대상이 아닙니다.
